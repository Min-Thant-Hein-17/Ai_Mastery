## 📝 Notes: Common Machine Learning Algorithms

Although there are many machine learning algorithms, only a small number are commonly used in real-world projects. Learning these core algorithms provides a strong foundation for solving most business and data science problems.

| Task                                    | Common Algorithms                                                                   |
| --------------------------------------- | ----------------------------------------------------------------------------------- |
| Predict numerical values (Regression)   | Linear Regression                                                                   |
| Predict categories (Classification)     | Logistic Regression, Naive Bayes                                                    |
| Work with structured/tabular data       | Decision Tree, Random Forest, XGBoost                                               |
| Find hidden groups in data (Clustering) | K-Means, DBSCAN                                                                     |
| Reduce the number of features           | Principal Component Analysis (PCA)                                                  |
| Learn complex patterns (Deep Learning)  | Artificial Neural Networks (ANN), Convolutional Neural Networks (CNN), Transformers |

### Key Takeaways

* Choosing the right algorithm is important, but it is only part of building a successful machine learning solution.
* A large portion of the work involves:

  * Cleaning and preparing the data.
  * Clearly defining the problem.
  * Selecting the simplest model that performs well instead of using a more complex model unnecessarily.
* Building a solid understanding of these fundamental algorithms is enough to solve many common real-world machine learning problems before exploring more advanced techniques.
